# Security

Reports should include the affected version, reproducible steps using synthetic
data, and expected impact. Before publication, the repository owner should
configure a private reporting channel or enable GitHub private vulnerability
reporting. Do not post secrets or personal datasets in public issues.

Read README for the trust model and operational limits. Tests are evidence for
specific behavior, not a guarantee against every failure. Review dependency
advisories before upgrades; avoid forced incompatible downgrades.
