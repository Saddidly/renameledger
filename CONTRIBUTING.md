# Contributing

Start with README and architecture notes. Describe the concrete problem before
opening a broad feature change. Keep changes focused, preserve documented data
formats, and include regression tests for storage or filesystem safety changes.

Run the documented checks before submitting a pull request. Include commands,
results, and platforms you could not exercise. Hosted CI status depends on the
repository where you publish this project. Use synthetic fixtures and never
commit personal data, credentials, databases, or local build artifacts.

Contributions are licensed under MIT.
